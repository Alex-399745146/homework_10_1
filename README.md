## Реализация функций

- [Функция filter_by_state() принимает на вход список словарей с данными о банковских операциях и параметр state, возвращает новый список, содержащий только те словари, у которых ключ state содержит переданное в функцию значение. Параметр state функции имеет значение по умолчанию 'EXECUTED.'](src/processing.py)
- [Функция sort_by_date() принимает на вход список словарей и параметр порядка сортировки, возвращает новый список, в котором исходные словари отсортированы по дате. Параметр порядка сортировки функции имеет значение по умолчанию 'True'](src/processing.py)

## Использование
В файле [main.py](main.py) основная логика она пока не дописона, но тестовые вызовы функций уже имеются. 
Структура проекта выстраена на инструменте poetry [pyproject.toml](pyproject.toml)

Для активации виртуального пространства введите след. команду:
```sh
.\.venv\Scripts\activate
```
Для проверки кода установленными линтерами.
В терминале введите след. команды:
```sh
flake8 src
```
```sh
isort src
```
```sh
black srс
```
```sh
mypy sr
```
